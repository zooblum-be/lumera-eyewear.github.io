# LUMÉRA Eyewear

**See the Difference.**

A refined eyewear storefront concept with a boutique-inspired black, cream, and champagne palette.

## Highlights
- 108 products across 10 eyewear categories
- Sunglasses, eyeglasses, blue light, prescription frames, readers, sport, kids, luxury and accessories
- Search, filtering and sorting
- Product detail pages with style notes and service information
- Cart and wishlist demo behavior
- Collections, sale and new-arrival pages
- Responsive layout
- Local image assets bundled inside the project
- GitHub Pages ready
